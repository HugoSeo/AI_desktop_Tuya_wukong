StatusBar Singleton

全局状态栏，创建在 lv_layer_top() 上，跨页面存活。支持 Full/Minimal 两种模式。

Full 模式

09:30 📅2   ⏰1 📶

Minimal 模式 (Home 页)

📶

API

函数说明
ui_comp_statusbar_init()初始化单例（仅调用一次）
ui_comp_statusbar_refresh(props)刷新所有字段（时间、日历、闹钟、WiFi、电量）
ui_comp_statusbar_set_visible(bool)显示/隐藏状态栏
ui_comp_statusbar_set_mode(mode)切换 FULL / MINIMAL 模式

Props 结构

  • hour / minute uint8_t — 当前时间
  • calendar_count uint8_t — 今日日程数
  • alarm_count uint8_t — 闹钟数
  • wifi_strength uint8_t — WiFi 信号强度 (0-3)
  • battery_level uint8_t — 电量百分比 (0-100)
  • is_charging bool — 是否充电中
  • wifi_connected bool — 是否在线

电量颜色规则

>40% 正常
11-40% 警告
≤10% 低电量

使用示例

// 初始化 (ui_app_init 中调用一次)
ui_comp_statusbar_init();

// 页面 on_enter 中控制模式
ui_comp_statusbar_set_mode(UI_STATUSBAR_MODE_FULL);
ui_comp_statusbar_set_visible(true);

Button Multi-instance

多风格按钮组件：Primary / Secondary / Text / Icon 四种填充，外加圆形按钮（透明环 + 按下半透明填充，仿 iPhone 锁屏）和图标+文字按钮（图标可在左/右/上）。可禁用。

⚠️ 所有按钮在创建时会 lv_obj_remove_style_all() 清掉 LVGL 默认主题（阴影/内边距），再贴自有样式，确保前景（图标/文字）居中无偏移。

函数说明

ui_comp_btn_circle_create(parent, icon_src, text, cb)圆形按钮；text=NULL 为纯图标，否则圆下方带文字

使用示例

// Primary 按钮
lv_obj_t *btn = ui_comp_btn_create(parent, "确定", my_click_cb);

// Secondary 风格
lv_obj_t *btn2 = ui_comp_btn_create_styled(parent, "取消",
    UI_COMP_BTN_SECONDARY, cancel_cb);

// 图标按钮
lv_obj_t *vol = ui_comp_btn_icon_create(parent, &icon_volume, vol_cb);

// 圆形按钮 (纯图标 / 带文字)
ui_comp_btn_circle_create(parent, &icon_camera, NULL, cam_cb);
ui_comp_btn_circle_create(parent, &icon_call, "通话", call_cb);

// 图标+文字按钮 (图标在左 / 在上)
ui_comp_btn_create_with_icon(parent, &icon_play, "播放",
    UI_COMP_BTN_PRIMARY, UI_COMP_BTN_ICON_LEFT, play_cb);
ui_comp_btn_create_with_icon(parent, &icon_gear, "设置",
    UI_COMP_BTN_TEXT, UI_COMP_BTN_ICON_TOP, gear_cb);

// 注: create_with_icon 的 cb 不带 user_data。若需按实例区分,
//     传 cb=NULL 再自行 lv_obj_add_event_cb(btn, cb, LV_EVENT_CLICKED, data)

// 禁用
ui_comp_btn_set_enabled(btn, false);

Item 结构

static ui_comp_list_item_t items[] = {
    { .text = "Wi-Fi",  .secondary = "已连接", .icon = &icon_wifi, .on_click = wifi_cb },

    { .text = "亮度",   .secondary = "自动",  .icon = &icon_bri,  .on_click = bri_cb },
};
lv_obj_t *list = ui_comp_list_create(parent, items, 3);

// 动态更新
items[1].secondary = "50%";
ui_comp_list_set_items(list, items, 3);

Link Multi-instance

带颜色 + 下划线的可点击文字（如对话页"查看图片"）。arg 被拷贝进 widget（LVGL 堆），随 widget 删除自动释放——调用方可随意清除父节点不泄漏；每次点击把拷贝传回 cb。

API

函数说明
ui_comp_link_create(parent, text, cb, arg, arg_len)创建超链接标签（text 由调用方先做 i18n 解析；arg 拷贝 arg_len 字节，NULL/0 表示无参数）

使用示例

static void view_image_cb(const void *arg, uint32_t len) {
    // arg 是创建时拷贝的文件名
}
const char *name = "img_0007.jpg";
lv_obj_t *link = ui_comp_link_create(bubble, ui_i18n_text(UI_TEXT_PICTURE_VIEW),
                                    view_image_cb, name, strlen(name) + 1);

Picture Multi-instance

纯渲染器：在父容器中央按原始尺寸绘制一块 RGB565 缓冲（不做 JPEG 解码、不依赖任何业务/平台头文件——解码在 ui_svc_picture）。缓冲所有权由 set_rgb565 的 free_fn 决定。

API

函数说明
ui_comp_picture_create(parent)创建图片画布
ui_comp_picture_set_rgb565(obj, w, h, data, free_fn)显示 RGB565 图（free_fn==NULL 仅引用、调用方保留所有权；非 NULL 则所有权转移给 widget，替换/清除/删除时自动 free_fn(data)）
ui_comp_picture_clear(obj)释放持有的缓冲并显示空占位

使用示例

lv_obj_t *pic = ui_comp_picture_create(screen);

// 借用服务缩略图列表：零拷贝，调用方保留所有权
ui_comp_picture_set_rgb565(pic, w, h, thumb->rgb565, NULL);

// 大图：所有权转移给 widget
ui_comp_picture_set_rgb565(pic, w, h, big, ui_svc_picture_free_rgb565);

RingAlarm Singleton

闹钟/提醒/倒计时到点时弹出的全局响铃覆盖层（仅 UI 线程调用）。由 ui_svc_tm 的到点事件触发。

类型枚举（ui_ring_kind_t）

  • UI_RING_KIND_ALARM — 闹钟：显示 Snooze + Stop
  • UI_RING_KIND_REMINDER — 提醒：仅 Stop
  • UI_RING_KIND_COUNTDOWN — 倒计时：仅 Confirm

API

函数说明
ui_comp_ring_alarm_show(kind, id, message, on_stop)弹出响铃（id 可 NULL/空）；用户点击主操作时在 overlay 关闭前回调 on_stop，由调用方接到对应业务动作
ui_comp_ring_alarm_dismiss()手动关闭

使用示例

static void on_stop(ui_ring_kind_t kind, const char *id) {
    // 确认闹钟 / 停止倒计时…
}
ui_comp_ring_alarm_show(UI_RING_KIND_ALARM, alarm_id, "起床啦", on_stop);

API

函数说明
ui_comp_popup_show(type, title, msg, cb)显示弹窗 (自动 dismiss 上一个)
ui_comp_popup_toast(msg, duration_ms)显示 Toast 提示 (默认 2s 自动消失)
ui_comp_popup_dismiss()关闭弹窗/Toast

类型枚举

UI_COMP_POPUP_INFO
UI_COMP_POPUP_CONFIRM
UI_COMP_POPUP_LOADING
UI_COMP_POPUP_TOAST

回调

ui_comp_popup_cb_t — void (*)(bool confirmed)，Confirm 时 true=确认 / false=取消；Info 时 true=确定。

使用示例

static void on_reset_result(bool confirmed) {
    if (confirmed) do_factory_reset();
}

// 确认弹窗
ui_comp_popup_show(UI_COMP_POPUP_CONFIRM,
    "确认", "是否恢复出厂设置？", on_reset_result);

// Loading 弹窗 (无回调)
ui_comp_popup_show(UI_COMP_POPUP_LOADING,
    "请稍候", "正在连接...", NULL);

// 操作完成后手动关闭
ui_comp_popup_dismiss();

// Toast 轻提示 (2秒自动消失)
ui_comp_popup_toast("已复制到剪贴板", 2000);

// 3秒 Toast
ui_comp_popup_toast("网络已断开", 3000);
