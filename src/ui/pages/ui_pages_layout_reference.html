事件处理流程

🔀 手势：左滑 → 进入 Chat 页

用户在屏幕上 左滑 (LV_DIR_LEFT)
→ gesture_cb() 捕获 LV_EVENT_GESTURE（子控件含 LV_OBJ_FLAG_GESTURE_BUBBLE 使手势冒泡到 screen）
→ 判断方向 == LV_DIR_LEFT
→ 调用 ui_route_push(UI_PAGE_CHAT)
→ 路由栈压入 Chat 页，触发 Home on_leave() + Chat on_create()

🌤️ 天气服务回调

ui_svc_weather 数据更新（每 30 分钟拉取一次）
→ 回调 on_weather_updated()
→ 调用 refresh_weather()
→ 若天气不可用 → 隐藏 s_card_weather
→ 若可用 → 更新 s_lbl_weather_main / s_lbl_weather_range 文本

📞 通话快捷按钮 → 联系人页

CLICK on btn_call
→ call_click_cb()
→ 检查 ui_feature_available(UI_FEATURE_ID_CALL)
→ 可用 → ui_route_push(UI_PAGE_CONTACTS)（先在联系人页选 App / 设备，再进呼叫页）
→ 不可用 → toast UI_TEXT_FEATURE_UNAVAILABLE
按钮创建时若 ui_feature_available(UI_FEATURE_ID_CALL) 返回 false，则按钮置灰（disabled）。

⏱️ 定时刷新（dirty flag 驱动）

框架每 30ms 调用 ui_tick → 检查 dirty 位图
→ 若 UI_STATE_GROUP_SYSTEM 脏 → refresh_datetime()：读取本地时间，去重比较后更新 s_lbl_time / s_lbl_date
→ 若 UI_STATE_GROUP_SETTINGS 脏 → 失效日期去重守卫（s_last_mon/mday = 0xFF），重新刷新（语言切换后重新格式化日期）
→ refresh_weather()：刷新天气卡片
→ 若 dirty == 0xFFFFFFFF（首次进入）→ refresh_alarm()

生命周期

回调行为
on_create构建完整控件树，注册手势回调，注册 ui_svc_weather_set_cb，初始刷新时间/天气/闹钟，禁用 lv_scr_act 滚动
on_enter设置 statusbar 为 MINIMAL 模式并显示；按 dirty 位刷新时间/天气/闹钟；SETTINGS 脏时重刷日期
on_leave恢复 statusbar 为 FULL 模式
on_destroy注销天气回调（set_cb(NULL)），HIDDEN + lv_obj_del_async 安全销毁，清空所有指针和去重守卫

💬 消息接收流程

业务层 tuya_ai_toy 发送显示消息
→ tuya_ai_display_msg() → tuya_ai_display_stub.c 路由
→ 调用 ui_page_chat_on_msg(msg, len, display_tp)
→ 按 display_tp 类型分发：
  ├─ TY_DISPLAY_TP_HUMAN_CHAT → chat_append_user()：创建用户气泡(蓝色, 右对齐)
  ├─ TY_DISPLAY_TP_AI_CHAT_START → chat_append_ai_start()：创建 AI 气泡(灰色, 左对齐)，初始化流式状态
  ├─ TY_DISPLAY_TP_AI_CHAT_DATA → chat_append_ai_data()：追加文本到当前 AI 气泡
  ├─ TY_DISPLAY_TP_AI_CHAT_STOP → chat_append_ai_stop()：结束流式，最终布局刷新
  ├─ TY_DISPLAY_TP_CHAT_MODE / TY_DISPLAY_TP_MODE_NOTIFY → refresh_mode_label()：更新模式文本
  ├─ TY_DISPLAY_TP_AI_IMAGE → chat_append_image_link(pic_name)：创建"查看图片"超链接气泡
  ├─ TY_DISPLAY_TP_CLEAR_ATTACHMENT → clear_attachment()：隐藏附件预览栏
  └─ STAT_* / CHAT_STAT → refresh_stat_label()：更新状态文本

📝 流式文本处理细节

chat_append_ai_data(text, len)：
→ UTF-8 安全截断：检查多字节边界（0xC0/0x80 判断）
→ lv_label_ins_text() 追加到流式 label 末尾
→ 累加 s_stream_pending_layout += len
→ 若累计 ≥ 32 字节（STREAM_LAYOUT_THRESHOLD）：
    重置计数 → lv_obj_update_layout() → scroll_to_bottom()
→ 气泡滑动窗口：超过 6 条时 evict_oldest_bubble() 删除最旧气泡

🖼️ AI 生图：查看图片链接

TY_DISPLAY_TP_AI_IMAGE 携带图片文件名
→ chat_append_image_link(pic_name)：创建超链接气泡（"查看图片"）
→ 用户点击链接 → view_image_link_cb()
→ ui_svc_picture_view_request(pic_name)（异步解码）
→ 解码完成 → on_picture_view() → 显示 s_img_overlay（全屏黑底）
→ 用户点击 overlay → img_overlay_click_cb() → 隐藏 overlay + 释放 buffer

📎 附件预览栏（AI 识图 hand-off，ADR-0003）

on_enter() 调用 try_show_attachment()
→ ui_svc_picture_take_pending_attachment() 获取待发送图片
→ 有数据 → 显示 s_attach_bar，缩略图写入 s_attach_thumb
→ 用户点击 ✕ → attach_close_cb() → clear_attachment()（仅 UI 隐藏，不取消发送）
→ 业务层发送完成后发 TY_DISPLAY_TP_CLEAR_ATTACHMENT → 再次清除
